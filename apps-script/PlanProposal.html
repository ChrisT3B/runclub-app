Plan Proposal

Build a prompt from an athlete sheet, paste it into an AI, import the reply for review, accept it into the Plan tab, then publish the athlete's plan.

1. Build the prompt

Your direction comes from the athlete sheet's Brief tab. Fill it in before building.

Copied.

2. Import the AI's reply

Uses the sheet in step 1. Paste the whole reply, including the code block.

3. Accept into Plan

Copies the imported proposal into the Plan tab: phases, sessions, notes and rationale. Rows marked Locked (column S = Yes) are never changed. Totals, dates and flags are left to the Plan tab's formulas.

4. Publish the athlete plan

Make your final edits in the Plan tab and in column C of the Athlete summary tab first. Publish builds the athlete's plan from the Athlete view and the Athlete summary only, values only, in the published plans folder, with a PDF next to it. Publishing again updates the same file, so the athlete's link does not change.
